Dokumentasi Hasil Implementasi dan Pengujian Sistem Penc arian Jurnal

4.1 Implementasi Sistem

Sistem pencarian jurnal penelitian berbasis Content-Based Filtering telah berhasil diimplementasikan menggunakan Flask (Python) sebagai backend dan HTML5, CSS3, JavaScript sebagai frontend. Sistem ini mengintegrasikan algoritma TF-IDF (Term Frequency-Inverse Document Frequency) dan Cosine Similarity untuk melakukan ranking relevansi jurnal ilmiah berdasarkan query pengguna.

4.1.1 Interface Halaman Utama

Halaman utama sistem dirancang dengan pendekatan user-centered design untuk memudahkan pengguna dalam melakukan pencarian jurnal. Interface menggunakan modern design dengan gradient background dan form yang clean dan intuitif.

  • Header: Judul sistem dengan gradient background yang menarik
  • Search Form: Input field untuk query penelitian

Analisis Implementasi

Interface menggunakan gradient background (biru-ungu) untuk menciptakan tampilan yang modern dan profesional. Form validation dilakukan secara client-side menggunakan JavaScript untuk memastikan query tidak kosong sebelum melakukan pencarian. Sistem menggunakan CSS Grid dan Flexbox untuk responsive layout yang dapat beradaptasi dengan berbagai ukuran layar (desktop, tablet, mobile).

4.1.4 Modul Content-Based Filtering

Modul CBF merupakan inti dari sistem yang bertanggung jawab untuk melakukan ranking jurnal berdasarkan relevansi dengan query. Implementasi dilakukan dalam beberapa tahap:

1. Text Preprocessing

Tahap Proses Contoh
Lowercase Konversi semua huruf ke lowercase "Algoritma Greedy" → "algoritma greedy"
Tokenization Memecah teks menjadi token/kata "algoritma greedy" → ["algoritma", "greedy"]
Stopword Removal Menghapus kata umum (the, is, and, dll) ["the", "greedy", "algorithm"] → ["greedy", "algorithm"]
Lemmatization Mengembalikan kata ke bentuk dasar "algorithms" → "algorithm", "routing" → "route"

Implementation Detail: Preprocessing menggunakan NLTK WordNetLemmatizer dan stopwords corpus. Average processing time: 0.5-1 detik per dokumen untuk abstrak standar (200-300 kata).

2. TF-IDF Vectorization

Sistem menggunakan TfidfVectorizer dari scikit-learn dengan konfigurasi sebagai berikut:

  • max_features: 1000 (membatasi vocabulary size untuk efisiensi)
  • ngram_range: (1, 2) - menggunakan unigram dan bigram
  • min_df: 2 - term harus muncul minimal di 2 dokumen
  • max_df: 0.8 - ignore terms that appear in >80% of documents
  • sublinear_tf: True - use logarithmic term frequency
Hasil Implementasi TF-IDF

Pada testing dengan 20 jurnal hasil pencarian "Algoritma Greedy untuk rute tercepat", sistem berhasil menghasilkan TF-IDF matrix dengan dimensi (20, 228) yang berarti 20 dokumen dengan 228 unique terms setelah preprocessing. Matrix ini kemudian digunakan untuk perhitungan Cosine Similarity.

3. Cosine Similarity Ranking

Setelah vectorization, sistem menghitung similarity score antara query vector dan setiap document vector menggunakan Cosine Similarity. Formula yang digunakan:

Cosine Similarity = (A · B) / (||A|| × ||B||)

Di mana:
A = Vector query (user input)
B = Vector dokumen (paper)
||A|| = Magnitude/length vector A
Nilai berkisar 0-1: 1 = identik, 0 = tidak ada kesamaan

Paper dengan similarity score tertinggi akan diranking di posisi atas. Skor dikonversi ke persentase (0-100%) untuk kemudahan interpretasi pengguna.

4.3 Pembahasan

4.3.1 Kelebihan Sistem

Berdasarkan hasil implementasi dan pengujian, sistem pencarian jurnal berbasis Content-Based Filtering memiliki beberapa kelebihan:

Kelebihan
  • Ranking Otomatis: Sistem secara otomatis melakukan ranking berdasarkan relevansi, memudahkan user menemukan paper yang paling sesuai
  • Multi-Source: Mendukun multipel sumber data (Mendeley, Semantic Scholar, Google Scholar)
  • Query Bahasa Indonesia: Dapat menangani query dalam bahasa Indonesia dengan baik melalui preprocessing yang tepat
  • User-Friendly Interface: Design modern, clean, dan mudah digunakan
  • Fast Response: Response time ~15 detik untuk 20 hasil termasuk cukup cepat
  • Scalable: Arsitektur modular memudahkan penambahan fitur dan sumber data baru

4.3.2 Keterbatasan Sistem

Meskipun sistem berfungsi dengan baik, terdapat beberapa keterbatasan yang perlu diperhatikan:

  • Dependency pada API Eksternal: Sistem bergantung pada ketersediaan dan kualitas API/sumber data eksternal (Mendeley, Semantic Scholar). Jika API mengalami downtime atau rate limiting, sistem tidak dapat berfungsi optimal
  • Bahasa Processing: Sistem dioptimalkan untuk bahasa Inggris. Query bahasa Indonesia dapat berhasil, tapi hasil akan lebih baik jika paper juga dalam bahasa Indonesia (yang jumlahnya terbatas di database internasional)
  • No Personalization: Sistem menggunakan CBF murni tanpa collaborative filtering, sehingga tidak ada personalisasi berdasarkan history atau preferences user
  • Limited Metadata: Beberapa paper dari Mendeley/Scholar memiliki metadata yang tidak lengkap (missing abstract, authors, dll)

4.3.3 Saran Pengembangan

Untuk pengembangan selanjutnya, beberapa fitur yang dapat ditambahkan:

  • Implementasi caching untuk menghindari duplicate requests dan mempercepat response time
  • Menambahkan collaborative filtering untuk mendapatkan personalized recommendations
  • Integrasi dengan lebih banyak sumber data akademik (IEEE Xplore, arXiv, PubMed, dll)
  • Implementasi user account dan history untuk tracking pencarian sebelumnya
  • Menambahkan fitur citation network visualization
  • Export ke reference management tools (Zotero, EndNote) dengan one-click
  • Implementasi full-text search jika memiliki akses ke full paper PDF
